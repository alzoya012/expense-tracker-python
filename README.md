# Expense Tracker

A simple Python-based Expense Tracker that helps users manage their daily expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Save expenses automatically
- Load saved expenses when the program starts

## Technologies Used

- Python
- JSON

## How to Run

1. Download or clone this repository.
2. Open Command Prompt in the project folder.
3. Run:

python expense_tracker.py

## Project Files

- expense_tracker.py - Main Python program
- expenses.json - Stores saved expense data
- README.md - Project documentation
